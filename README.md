## Сабақ тақырыбы
Ақтамберді жырау шығармашылығы

## Сабақ мақсаты
- Ақтамберді жырау туралы жалпы мағлұмат беру;
- жыраулық поэзияның ерекшеліктерін анықтау;
- халықтық тақырыптар мен көркемдік ерекшеліктерін талдау;
- оқушылардың шығармашылық ой-өрісін дамыту.

## Күтілетін нәтиже
Оқушылар:
- Ақтамберді жыраудың өмірі мен шығармашылығы туралы біледі;
- жыраулық поэзияның тақырыптары мен ерекшеліктерін ажыратады;
- өлеңнің идеясы, образдары мен көркем бейнелерін талдай алады;
- өз пікірін еркін, дәлелді түрде білдіреді.
